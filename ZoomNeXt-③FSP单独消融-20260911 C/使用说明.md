# 浅层引导的 MHSIU 权重修正：实验版本

本目录是独立的新版本，以恢复的 FEDER/ZoomNeXt 为基础。原始 zoomnext.py、layers.py 未修改；不替换 E:/ZoomNeXt/FDER-SG-20260907 或已完成实验的代码。

## 本次改动

新增 methods/zoomnext/weight_guided.py，导出 EffB1_ZoomNeXt_WeightGuided。

方向一：使用中尺度输入的最浅层编码特征，在第 3、2 层 MHSIU 中对原权重 logits 加上一个学习到的修正量。修正量由当前中尺度特征与对齐后的浅层特征共同生成。每个 head、每个像素各有 large/medium/small 三个权重，仍由 softmax 归一化，三者之和为 1。

公式：a = softmax(z_original + delta(current_medium, shallow_feature))。

被加权的三尺度特征及其原融合路径保持原设计。与上次 FEDER+SG 的区别是：上次在融合后增强特征；这次在融合前修正选择权重。没有加入 FSP、MSCA 或旧版融合后 SG。

修正分支末层权重/偏置均为零初始化，所以初始权重选择与原 MHSIU 完全相同。首次反向时末层可学习，上游引导投影的梯度通常要在末层更新后才能非零。这是初始化性质，不是梯度断开。没有通过跳过零分支的方式阻断训练。

方向二：保留恢复版的 FDE（第 2、1 层，各执行一次，在与上一级解码特征相加前）与边缘头，但将二者改为独立开关。这是拆分已有机制的消融能力，不宣称新增了一套已验证有效的频率算法。FDE 仍然是平均池化平滑分量与残差细节分量的简化实现，不能写成完整复现 FEDER 的小波机制。

FDE/edge 关闭时不创建该分支的可训练参数；关闭所有开关可恢复普通基线的参数结构；只开 FDE+edge 可恢复原 FEDER 的参数结构。

## GPU 1、nohup 启动单项新设计

```bash
cd /home/gyz/ZoomNeXt
LOG="weight_guidance_$(date +%Y%m%d_%H%M%S).log"
nohup /home/gyz/anaconda3/envs/zoomnext/bin/python -u run_weight_guided.py \
  --variant guidance --gpu 1 --data-cfg dataset.yaml \
  > "$LOG" 2>&1 < /dev/null &
echo "PID=$! 日志=$LOG"
```

复制纯代码块，不要把转义后的 \_ 或 HTML 空格粘进终端。只启动一次。
日志首先应显示模型 EffB1_ZoomNeXt_WeightGuided、VARIANT guidance、FLAGS (True, False, False)，随后才是检查结果和训练进度。此项不含 edge 损失是正常的；它只验证权重引导。

launcher 检查 GPU、模型开关、数据目录，打印每个数据集图像/掩码/配对数量，执行 CPU 回归测试，然后在 weight_guided_runs/ 中保存源码、解析后的配置、数据路径、环境和哈希，再从该快照启动训练。结果位于本次运行目录的 results/，last_weight_guided_run.txt 记录该位置。数据路径在复制前解析为绝对路径。

## 对照边界

继承原训练超参数和随机种子，不自动修改学习率调度，也不加载已经训练好的 FEDER 整网权重。如果服务器仍是 6958 对训练样本、CAMO 测试 244 张，启动器会显示相关计数与警告；这些不等于已经完成数据划分审计。原调度里程碑为 101000 步，按 4040 个训练样本预设；与当前实际样本数的偏差仍然存在。为了与旧结果对照本次没有偷偷改变它。
若修正数据划分或调度，必须将新版本基线与新方法同时放到修正后的设置下训练，不能与旧设置的结果混作严格消融。
所有设计是待验证假设，未证明提高精度或具备文献新颖性。最终须比较全部四个测试集，而不是只选择有收益的指标。
